# CS330
My CS-330 Computer Graphics and Visualization portfolio, including my 3D scene project and design decisions.

### 1. How do I approach designing software?

When designing software, I like to start with a plan and work on one thing at a time. This course helped me understand how to use basic shapes to create a 3D scene. For my project, I created a desk with a cup, notebook and pencil. I had to think about the size, position, and appearance of each object. I learned that it is important to test my work as I go instead of waiting until everything is finished. I can use this same approach in future projects by planning first and making changes when needed.

### 2. How do I approach developing programs?

When developing programs, I like to take my time and make sure everything works before moving forward. During this project, I worked with C++ and OpenGL to create my scene. I had to make several changes to my code, especially when working with lighting and textures. Some things did not work the first time, so I had to go back and fix them. I learned that testing my code after making changes helps me find problems. As I worked through each milestone I became more comfortable understanding my code and fixing errors.

### 3. How can computer science help me in reaching my goals?

Computer science is helping me build the skills I need for my future career. This course taught me more about programming, problem-solving, and creating 3D objects using code. Before taking this course, I did not know much about computer graphics or how they worked. Now I have a better understanding of how different shapes, lighting, and textures come together to create a scene. Even though I want to work in software engineering, I know these skills can help me with other programming projects. This experience also showed me the importance of being patient and continuing to learn when something is difficult.
